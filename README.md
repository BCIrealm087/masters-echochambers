# Echo chambers in Brazil’s 2022 presidential election

This Computer Science master’s project studies how to detect and characterize echo chambers in Twitter data collected by Interfaces during Brazil’s 2022 presidential election. The source is the Interfaces Twitter Elections Dataset (ITED-Br). The earlier manuscript reports 282 million posts in the parent collection. Each analysis in this project will describe the subset it actually uses.

The research has two connected aims. The first is to determine when a community found in a graph has enough evidence of selective interaction or information circulation to warrant the term *echo chamber*. The second is to make it possible to study what happens inside those communities. For example, do groups use different language to support one candidate and attack another? Which sources circulate within a group, and which cross its boundaries? Questions about belief and trust will require an explicit account of what the observed behavior can support.
